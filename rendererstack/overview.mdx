RendererStack is a modular rendering system for large outdoor scenes. It is built around specialized renderers that handle level rendering without relying on thousands of active GameObjects in the scene.

The current documented renderer is **Terrain Object Renderer**. Other renderer workflows are in development.

## Renderers

- **Terrain Object Renderer** — renders large terrain objects such as trees, bushes, and rocks.
- **Detail Object Renderer** — in development.
- **Sectorize** — terrain streaming. Documentation is coming later.
