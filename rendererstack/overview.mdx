RendererStack is a modular rendering system for large outdoor scenes. It is built around specialized renderers that handle level rendering, terrain object rendering, and terrain streaming.

The current documented tools are **Terrain Object Renderer** and **Sectorize**.

## Renderers

- **Terrain Object Renderer** — renders large terrain objects such as trees, bushes, and rocks.
- **Sectorize** — streams terrain sectors with additive scenes.
- **Detail Object Renderer** — in development.
