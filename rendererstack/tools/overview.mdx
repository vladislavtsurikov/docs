RendererStack tools are specialized renderers for large scenes. Each renderer focuses on a specific type of scene data so it can optimize rendering, culling, and runtime interaction for that workflow.

## Available tools

<CardGroup cols={2}>
  <Card title="Terrain Object Renderer" icon="trees" href="/rendererstack/tools/terrain-object-renderer">
    Render large terrain objects with GPU Instanced Indirect, frustum culling, terrain-cell occlusion, colliders, and scripting support.
  </Card>
  <Card title="Terrain Object Renderer features" icon="sparkles" href="/rendererstack/tools/terrain-object-renderer-features">
    See the main rendering, culling, collider, scripting, and conversion features.
  </Card>
  <Card title="Sectorize" icon="map" href="/rendererstack/tools/sectorize">
    Stream terrain sectors around cameras using additive scene loading.
  </Card>
</CardGroup>
