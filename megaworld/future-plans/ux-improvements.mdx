## Modified Setting Highlight

In any place that has settings — Preferences, Inspector, a tool panel — each field whose value differs from the default shows a small marker next to it, along with a reset button that resets only that field to its default without affecting anything else.

```
  Maximum History:  [ 100 ]  ↺
  Maximum Brush Size:  [ 200 ]      ← no marker, value is default
```

This solves a common problem: something stopped working as expected, but it's unclear what was changed. With these markers, the artist or developer immediately sees every deviation from the standard state and can precisely roll back only the field they need.

Applicable everywhere: in Preferences, in group and prototype settings, in tool parameters.
