title: MegaWorld 2 — Future Plans
description: A look at the planned improvements and new systems coming in MegaWorld 2.
---

This section documents the planned design direction for MegaWorld 2. These are not yet implemented features — they are design proposals and architectural ideas that will shape the next major version.

The plans cover five areas:

- **Tool System & Modular Tools** — Rethinking how tools are registered, displayed, and organized in the editor
- **SelectionView Improvements** — Splitting the selection panel into a flexible library and browser system
- **Templates System Improvements** — Adding user-saveable JSON presets alongside existing C# templates
- **Undo Improvements** — A proper undo history panel with named operations and jump-to support
- **Preferences System** — A unified preferences window with search, built from all modules automatically
- **UX Improvements** — Small but impactful quality-of-life changes across the editor
