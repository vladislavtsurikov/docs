Advanced Object Stamper is a MonoBehaviour stamper tool for procedural placement of objects inside a defined area. You position and scale the stamper in the scene, then MegaWorld evaluates each active Group and fills the area with prototypes that pass your filters.

## How it works

When you click **Spawn**, Advanced Object Stamper processes each active Group in order:

1. Casts a ray downward from the stamper's position to find the surface.
2. Builds the box area from the result.
3. Runs the full object spawn pipeline for that area.

### Spawn pipeline for each group

1. Generates a random seed if needed.
2. Runs the scatter system over the box area to produce sample positions.
3. For each sample, casts a ray downward to find the surface hit point.
4. Selects a random prototype weighted by Success Settings.
5. Evaluates filter fitness (Mask Filter or Simple Filter) at the hit point.
6. Discards the sample with probability `1 − fitness`. Samples with `fitness = 0` are always skipped.
7. Calls the shared spawn routine which applies [Transform Components](/megaworld/transform-components/overview) and [Overlap Check Settings](/megaworld/overlap-check-settings/overview).

## Buttons

| Button | When visible | Action |
|---|---|---|
| **Fit To Terrain Size** | Not spawning | Expands the stamper bounds to cover all active terrains in the scene. |
| **Spawn** | Not spawning, Auto Respawn off | Runs the full spawn pass. |
| **Respawn** | Always | Unspawns all current objects and runs a fresh spawn pass. |
| **Unspawn Selected Prototypes** | Always | Removes all instances of the currently selected prototypes from the scene (shows a confirmation dialog). |
| **Cancel** | Currently spawning, Auto Respawn off | Cancels the in-progress spawn. |

## Shared systems

### Per-group settings

- [Random Seed Settings](/megaworld/shared-settings/random-seed-settings)
- [Scatter Settings](/megaworld/scatter-system/overview)
- [Filter Settings](/megaworld/mask-filters/overview)

### Per-prototype settings

- Success Settings
- [Overlap Check Settings](/megaworld/overlap-check-settings/overview)
- [Transform Components](/megaworld/transform-components/overview)

### Tool-level settings

- [Area](/megaworld/shared-settings/area-settings) — defines the stamper volume and bounds.
- [Stamper Tool Controller](/megaworld/shared-settings/stamper-tool-controller) — controls visualization and auto respawn.
- [Layer Settings](/megaworld/shared-settings/layer-settings) — specifies which physics layers are used for raycasts.

## Auto Respawn behavior

When **Auto Respawn** is on in the Stamper Tool Controller, changing any Group or prototype setting triggers a full respawn of that Group after the configured delay.

## When to use Advanced Object Stamper

Advanced Object Stamper is best when you want:

- a one-shot generation pass over a large area;
- a forest, rock field, or prop layout based on filters and scatter rules;
- a workflow where the result is tied to a scene object rather than painted manually.

## Notes

- Advanced Object Stamper does not support Unity/Terrain Detail. Use [Grass Stamper](/megaworld/tools/grass-stamper) for grass and detail density passes.
- Advanced Object Stamper does not support Unity/Terrain Texture. Use [Texture Stamper](/megaworld/tools/texture-stamper) for terrain texture passes.
- For the scatter system, a random seed is generated before each pass when **Random Seed** is set to auto-generate.
- Types (Groups) configured in Advanced Object Stamper are reusable assets. The same Group can be added to Advanced Object Brush and used for manual painting with the same filter and scatter rules.
