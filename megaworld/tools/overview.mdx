MegaWorld tools are split into two types: **MonoBehavior tools**, which attach to GameObjects in your scene, and **Editor Window tools**, which run inside a dedicated editor panel and interact through the Scene View.

## MonoBehavior tools

A MonoBehavior tool is attached to a **GameObject** in your scene and appears in the **Inspector** when that object is selected. Open them from Unity's top menu under `GameObject > Vladislav Tsurikov` — each entry creates a GameObject with the component already attached.

## Editor Window tools

An Editor Window tool works inside the **MegaWorld Window** and interacts with the scene through clicks, brushes, or handles. Open the window from `Window > Vladislav Tsurikov > Mega World > Window` or press `Alt + Z`, then click the **+** button in the Tools Panel to add the tool you need.
