## Supported resource type

- [Unity/Terrain Texture](/megaworld/resource-types/unity-terrain-texture)

## How it works

When you click **Stamp**, the tool finds all Unity Terrain tiles that intersect the stamper bounds. For each Group × terrain tile intersection it builds a `BoxArea` and evaluates the Mask Filter stack of every active prototype, writing the result directly to the terrain's alphamap. Multiple terrain tiles are processed in sequence automatically — no manual cell configuration is required.

## Buttons

| Button | When visible | Action |
|---|---|---|
| **Fit To Terrain Size** | Always (except during spawning with Auto Respawn off) | Expands the stamper bounds to cover all active terrains in the scene. |
| **Stamp** | Not currently spawning | Runs the full texture stamp pass. |
| **Cancel** | Currently spawning, Auto Respawn off | Cancels the in-progress stamp. |

## Stamper Tool Controller

| Setting | Description | Default |
|---|---|---|
| **Visualisation** | Shows the Mask Filter output as a colored overlay in the Scene View for the selected Group. | `true` |
| **Auto Respawn** | Automatically re-stamps whenever a setting changes. | `false` |
| **Delay Auto Respawn** | Seconds to wait after a change before triggering auto respawn. | `0.1` |

## Per-prototype settings

Each prototype has:

- [Mask Filter Settings](/megaworld/mask-filters/overview) — defines where and at what strength the texture is painted. The filter stack can include terrain filters (slope, height, aspect), procedural filters (noise, image), area masks, and operators such as Remap.
