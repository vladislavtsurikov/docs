MegaWorld is a multi-tool ecosystem. The Getting Started series is structured in layers — start with the foundation pages, then jump to the tutorial for the specific tool you want to use.

MegaWorld tools are split into two types: **MonoBehavior tools**, which attach to GameObjects in your scene, and **Editor Window tools**, which run inside a dedicated editor panel and interact through the Scene View.

## MonoBehavior tools

A MonoBehavior tool is attached to a **GameObject** in your scene and appears in the **Inspector** when that object is selected. Open them from Unity's top menu under `GameObject > Vladislav Tsurikov` — each entry creates a GameObject with the component already attached: **Advanced Object Stamper**, **Grass Stamper**, **Texture Stamper**, and **Gravity Spawner**.

## Editor Window tools

An Editor Window tool works inside the **MegaWorld Window** and interacts with the scene through clicks, brushes, or handles. Open the window from `Window > Vladislav Tsurikov > Mega World > Window` or press `Alt + Z`, then click the **+** button in the Tools Panel to add the tool you need: **Advanced Object Brush**, **Spray Brush**, **Brush Erase**, **Brush Modify**, **Edit**, **Precise Place**, **Pin**, **Brush Physics**, **Precise Physics**, **Explode Physics**, and **Physics Effects**.
