Before using any MegaWorld tool, it helps to understand how MegaWorld stores and organises the data it uses to spawn objects.

---

## Group

A **Group** is a container that holds spawn settings and a list of assets to place. It is stored as a ScriptableObject asset in your project and is reusable — you can assign the same Group to multiple tools or areas without duplicating settings.

Each Group is tied to a **Resource Type**, which determines the kind of object MegaWorld will place. The Resource Type is selected when creating a Group and cannot be changed afterwards:

<img
  style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '500px' }}
  src="/images/megaworld/get-started/create-group-menu.png"
  alt="Create Group menu showing available Resource Types."
/>

| Resource Type | What it places |
|---|---|
| **Unity/GameObject** | Prefab instances in the scene hierarchy |
| **Terrain Object** | Objects integrated with Unity's terrain system |
| **Unity/Terrain Detail** | Grass and detail meshes on Unity Terrain |
| **Unity/Terrain Texture** | Terrain texture layers painted onto Unity Terrain |

### Prototype

A **Prototype** is a specific asset assigned inside a Group — for example, a tree Prefab, a TerrainLayer, or a detail mesh. Each Group can hold multiple Prototypes and MegaWorld picks from them during spawning according to each prototype's weight and settings.

---

## Multiple Groups

Each tool can hold multiple Groups at once. This lets you stamp, paint, or spawn several different asset collections from a single tool without switching setups — for example, a **BigFir** group and a **SmallFir** group active at the same time.

## Prototype context menu

Right-clicking any Prototype opens a context menu with several useful actions.

### Apply Templates

**Apply Templates** lets you instantly load a pre-configured set of spawn settings onto a Prototype. Instead of manually tuning scatter density, transform components, filters, and overlap checks from scratch, you pick a template — for example **Small Trees**, **Big Trees**, **Rocks**, or **Cliffs** — and all relevant settings are applied in one click.

<img
  style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '640px' }}
  src="/images/megaworld/get-started/prototype-templates.png"
  alt="Apply Templates submenu showing Trees, Rocks, and Cliffs template categories."
/>

Templates are particularly useful when starting a new setup or when you want to reset a Prototype back to sensible defaults quickly.

### Copy and Paste Settings

**Copy All Settings** captures the complete configuration of a Prototype to the clipboard. You can then use **Paste All Settings** on another Prototype to duplicate the full setup, or use **Paste Settings** to transfer only a specific category:

<img
  style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '560px' }}
  src="/images/megaworld/get-started/prototype-copy-paste.png"
  alt="Prototype context menu showing Copy All Settings, Paste All Settings, and Paste Settings submenu."
/>

This is useful when you have several Prototypes that share most settings but differ in a few details — copy from one, then selectively paste onto the others.

### Active / Inactive

Each Prototype can be toggled **Active** or **Inactive** from the context menu. An inactive Prototype is excluded from spawning entirely — it is highlighted with a red border so it is immediately visible which ones are disabled.

<img
  style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '380px' }}
  src="/images/megaworld/get-started/prototype-active.png"
  alt="Prototype marked as inactive shown with a red border, with the Active toggle in the context menu."
/>

This is especially useful during testing and tweaking. For example, when painting terrain textures you can deactivate all but one Prototype to verify exactly how that single texture is being distributed — without the others interfering. Once you are satisfied, reactivate the rest.

## The core workflow

Every MegaWorld tool follows the same data setup steps:

1. **Create a Group** — in the MegaWorld Window or directly on the spawner component.
2. **Choose a Resource Type** — decide what kind of object you want to place.
3. **Add Prototypes** — drag your Prefabs, TerrainLayers, or meshes into the Group.
4. **Configure settings** — set scatter density, transforms, filters.
5. **Use a tool** — stamp, paint, spawn, or place using the active tool.
